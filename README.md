# Student Lifestyle Data Visualization

## Project Overview
This project analyzes student lifestyle data using Python
and data visualization techniques.

## Objectives
- Analyze entertainment preferences.
- Explore daily screen time.
- Identify preferred programming languages.
- Study the relationship between study time and sleep.
- Detect outliers in screen-time data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations
1. Bar Chart – Favorite Entertainment Platform
2. Histogram – Daily Screen Time
3. Pie Chart – Preferred Programming Language
4. Scatter Plot – Study Time vs Sleep Time
5. Box Plot – Daily Screen Time

## Conclusion
Data visualization helps us understand patterns
in student lifestyle data.
